# 1. Objet

Le présent document constitue le registre unique des risques du projet RHYAD.

Il recense l’ensemble des risques susceptibles d’affecter la programmation, la conception, la réalisation, la mise en service et la coordination documentaire du Campus CEVA.

Il constitue la référence commune utilisée par :

- le Maître d’Ouvrage ;
- l’AMO ;
- les bureaux d’études ;
- les entreprises ;
- les futurs Design Basis.

Le registre couvre uniquement les risques liés au projet. Les risques d’exploitation future du Campus sont exclus du présent document.

---

# 2. Domaine d’application

Le registre couvre notamment :

- les risques de programmation ;
- les risques techniques ;
- les risques réglementaires ;
- les risques liés au contexte local (ACAP) ;
- les risques environnementaux ;
- les risques documentaires ;
- les risques d’interfaces ;
- les risques liés au planning ;
- les risques liés aux décisions de conception.

# 5. Méthode d’évaluation

## Probabilité

| Niveau | Définition |
|---|---|
| 1 | Très faible |
| 2 | Faible |
| 3 | Moyenne |
| 4 | Forte |
| 5 | Très forte |

## Gravité

| Niveau | Définition |
|---|---|
| 1 | Faible |
| 2 | Limitée |
| 3 | Significative |
| 4 | Majeure |
| 5 | Critique |

## Criticité

Criticité = Probabilité × Gravité

| Score | Niveau |
|---|---|
| 1 à 4 | Faible |
| 5 à 9 | Modéré |
| 10 à 15 | Important |
| 16 à 25 | Critique |

# 11. Traitement des risques

Pour chaque risque devront être précisés :

- mesure d’évitement ;
- mesure de réduction ;
- mesure de transfert ;
- mesure d’acceptation ;
- risque résiduel.

---

# 12. Liens documentaires

Chaque risque devra référencer :

- le Programme Fonctionnel concerné ;
- le DT concerné ;
- le Design Basis concerné ;
- les décisions associées ;
- les actions associées.

---

# 13. Règles de gestion

1. Chaque risque possède un identifiant unique.
2. Un risque n’est décrit qu’une seule fois.
3. Les autres documents référencent le présent registre.
4. Toute modification du registre est enregistrée dans le CEVA-RHYAD-005-REGISTRE DES DECISIONS.
5. Les risques sont revus à chaque jalon du projet : APS, APD, PRO, DCE, EXE, Mise en service.
6. Les risques sont mis à jour après chaque réunion de projet ayant un impact sur leur évaluation ou leur traitement.
