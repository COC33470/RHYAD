# Objet

Le présent document a pour objet de recenser l'ensemble des données
techniques nécessaires à la conception de la fonction **F01 -- Réception
et Expédition**.

Il constitue le document de référence permettant de définir les besoins
fonctionnels, les contraintes d'exploitation et les données de
dimensionnement associées à cette fonction.
