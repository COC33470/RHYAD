# Objet

Le présent document a pour objet de recenser l'ensemble des données
techniques nécessaires à la conception de la fonction **F02 -- Stockage
des Matières Premières et Consommables**.

Il constitue le document de référence permettant de définir les besoins
de stockage, les contraintes d'exploitation, les exigences
réglementaires et les données de dimensionnement associées.
