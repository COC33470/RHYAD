# Objet

Le présent document a pour objet de recenser l'ensemble des données
techniques nécessaires à la conception des installations de maintenance
et des moyens d'exploitation du Campus CEVA.

Il définit les exigences permettant d'assurer une maintenance sûre,
efficace et compatible avec la continuité de la production.

## Remarques RHYAD

Les études devront notamment vérifier :

-   l'accessibilité de tous les équipements sans démontage majeur ;
-   la possibilité d'intervenir sur les équipements critiques avec un
    impact minimal sur la production ;
-   les réserves d'espace nécessaires au remplacement futur des
    équipements ;
-   la disponibilité locale des pièces de rechange et des compétences
    techniques, conformément à l'ACAP ;
-   les interfaces entre la GMAO, les automatismes et les équipements
    critiques.

Les données collectées alimenteront directement les DB Maintenance,
Architecture, Utilités, Électricité, Instrumentation et Process.

## Recommandation RHYAD

En phase APS, réaliser une revue de maintenabilité pour chaque
équipement critique afin de vérifier :

-   les dégagements de maintenance ;
-   les moyens de levage nécessaires ;
-   les cheminements d'extraction ;
-   les possibilités de maintenance sans arrêt de production ;
-   les réserves pour les extensions futures.
