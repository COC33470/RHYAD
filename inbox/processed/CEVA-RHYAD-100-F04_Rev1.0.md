# CEVA-RHYAD-100-F04

# Production des Autovaccins

**Version :** Rev1.0\
**Statut :** Validated\
**Référence :** CEVA-RHYAD-100-F04

------------------------------------------------------------------------

# 1. Objet

La fonction F04 -- Production des Autovaccins définit les exigences
fonctionnelles relatives aux activités de production des autovaccins
vétérinaires au sein du Campus CEVA RHYAD.

Elle couvre l'ensemble des espaces et fonctions nécessaires à la
fabrication, depuis l'introduction des matières préparées jusqu'au
transfert des produits vers les étapes de contrôle qualité, de
conditionnement ou de stockage intermédiaire.

Le présent document décrit exclusivement les besoins fonctionnels du
projet et ne définit ni les procédés de fabrication, ni les recettes de
production.

------------------------------------------------------------------------

# 2. Objectifs

-   production d'autovaccins conforme GMP/BPF ;
-   maîtrise des contaminations croisées ;
-   flexibilité des installations ;
-   protection du personnel, des produits et de l'environnement ;
-   disponibilité élevée des infrastructures critiques ;
-   évolutivité du Campus.

------------------------------------------------------------------------

# 3. Périmètre

La fonction couvre notamment :

-   salles de production ;
-   salles de culture ;
-   salles de préparation finale ;
-   locaux techniques associés ;
-   SAS personnel et matériel ;
-   zones de transfert ;
-   circulations de production.

Sont exclus :

-   procédures de fabrication ;
-   paramètres de production ;
-   recettes MES ;
-   procédures qualité ;
-   procédures d'exploitation.

------------------------------------------------------------------------

# 4. Exigences fonctionnelles

## F04-01 -- Conformité GMP/BPF

Les installations doivent permettre une production conforme aux
exigences réglementaires applicables.

## F04-02 -- Confinement

Les locaux doivent assurer un niveau de confinement adapté.

## F04-03 -- Traitement d'air des salles blanches

Le traitement d'air doit garantir : - la classe de propreté requise ; -
les cascades de pression ; - la température et l'humidité ; - les
renouvellements d'air ; - la continuité de fonctionnement.

Le traitement d'air des salles blanches est une infrastructure critique.

## F04-04 -- Flux

Les flux suivants doivent être maîtrisés : - personnel ; - matières ; -
produits ; - déchets ; - matériels.

## F04-05 -- Flexibilité

Les installations doivent permettre l'évolution des procédés.

## F04-06 -- Nettoyage

Les locaux et équipements doivent permettre le nettoyage et la
décontamination.

## F04-07 -- Traçabilité

Chaque opération doit être traçable.

## F04-08 -- Continuité d'activité

Les fonctions critiques doivent bénéficier d'un haut niveau de
disponibilité.
