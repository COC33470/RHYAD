CEVA-RHYAD-000-003

Glossaire

Version : V0.1
Statut : Validé – Base documentaire
Référence : CEVA-RHYAD-000-003

⸻

1. Objet

Le présent document constitue la référence terminologique unique du projet RHYAD.

Il définit les acronymes, les termes techniques, les concepts méthodologiques et les définitions spécifiques au projet afin de garantir une compréhension commune entre le Maître d’Ouvrage, l’AMO, les bureaux d’études, les entreprises et les autorités.

Principe RHYAD :

Un terme = une définition = une seule source.

Aucun autre document RHYAD ne doit redéfinir un terme présent dans ce glossaire.

⸻

2. Domaine d’application

Le présent glossaire s’applique à l’ensemble des documents RHYAD :

* Gouvernance (000)
* Programme Fonctionnel (100)
* Données Techniques (200)
* Design Basis (300)
* Réunions (400)
* Registres (500)
* Dossiers d’études (600)

⸻

3. Structure du glossaire

Le glossaire est organisé en cinq familles :

1. Acronymes
2. Définitions techniques
3. Principes méthodologiques RHYAD
4. Terminologie spécifique CEVA
5. Références normatives

9. Règles de gestion

1. Toute nouvelle définition est ajoutée au Glossaire avant d’être utilisée dans un autre document.
2. Une définition ne peut exister qu’à un seul endroit dans le référentiel RHYAD.
3. Les autres documents font référence au Glossaire et ne recopient pas les définitions.
4. Toute modification du Glossaire est enregistrée dans le CEVA-RHYAD-000-005 – Registre des Décisions.
5. Les termes spécifiques CEVA sont validés avec le Maître d’Ouvrage avant diffusion.
6. Les principes méthodologiques sont détaillés exclusivement dans CEVA-RHYAD-000-MTH01.
