# CEVA-RHYAD-100-F07

# Lavage, Stérilisation et Préparation des Équipements

**Version :** Rev1.0\
**Statut :** Validated\
**Référence :** CEVA-RHYAD-100-F07

------------------------------------------------------------------------

# 1. Objet

La fonction F07 -- Lavage, Stérilisation et Préparation des Équipements
définit les exigences fonctionnelles relatives au nettoyage, à la
décontamination, à la stérilisation, au séchage, au stockage et à la
préparation des équipements réutilisables nécessaires aux activités du
Campus CEVA RHYAD.

Elle couvre les équipements de production, de laboratoire et les
accessoires nécessitant une préparation avant leur remise en service.

Le présent document décrit les besoins fonctionnels du projet sans
définir les procédés de nettoyage, les cycles de stérilisation ni les
procédures opératoires.

------------------------------------------------------------------------

# 2. Objectifs

La fonction doit permettre :

-   le nettoyage des équipements réutilisables ;
-   la décontamination lorsque nécessaire ;
-   la stérilisation des matériels concernés ;
-   le séchage et le stockage avant réutilisation ;
-   la préparation des équipements pour les opérations de production ;
-   la maîtrise des contaminations croisées ;
-   la traçabilité complète des opérations.

------------------------------------------------------------------------

# 3. Périmètre

La fonction couvre notamment :

-   les locaux de lavage ;
-   les locaux de stérilisation ;
-   les autoclaves ;
-   les laveurs industriels ;
-   les zones de séchage ;
-   les zones de stockage des équipements propres ;
-   les SAS de transfert ;
-   les circulations associées.

Sont exclus :

-   les procédures de nettoyage ;
-   les paramètres de stérilisation ;
-   les qualifications d'équipements ;
-   les procédures qualité.

------------------------------------------------------------------------

# 4. Exigences fonctionnelles

## F07-01 -- Séparation des flux

Les équipements sales et les équipements propres doivent suivre des
cheminements distincts afin d'éviter toute recontamination.

## F07-02 -- Conditions environnementales

Les locaux doivent offrir des conditions adaptées aux différentes étapes
:

-   réception des matériels sales ;
-   lavage ;
-   séchage ;
-   stérilisation ;
-   refroidissement ;
-   stockage des matériels propres.

## F07-03 -- Préparation des équipements

Les équipements doivent pouvoir être préparés, assemblés et conditionnés
avant leur transfert vers les zones de production.

## F07-04 -- Traçabilité

Chaque équipement doit pouvoir être tracé :

-   identification ;
-   cycle de lavage ;
-   cycle de stérilisation ;
-   date ;
-   opérateur ;
-   destination.

## F07-05 -- Continuité d'activité

Les installations devront garantir la disponibilité des équipements
nécessaires aux activités critiques du Campus.

Les équipements critiques feront l'objet d'une analyse de redondance
adaptée.

## F07-06 -- Sécurité

Les installations doivent assurer :

-   la sécurité des opérateurs ;
-   la maîtrise des risques thermiques ;
-   la maîtrise des risques chimiques ;
-   la maîtrise des risques biologiques.

## F07-07 -- Maintenabilité

Les équipements devront être facilement accessibles afin de permettre :

-   la maintenance préventive ;
-   la maintenance corrective ;
-   les opérations de qualification ;
-   les contrôles réglementaires.
