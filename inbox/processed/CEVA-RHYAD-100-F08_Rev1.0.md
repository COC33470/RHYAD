# CEVA-RHYAD-100-F08

# Contrôle Qualité

**Version :** Rev1.0\
**Statut :** Validated\
**Référence :** CEVA-RHYAD-100-F08

------------------------------------------------------------------------

# 1. Objet

La fonction F08 -- Contrôle Qualité définit les exigences fonctionnelles
relatives aux activités de contrôle qualité (QC), d'analyse, de
qualification des lots et de libération des produits du Campus CEVA
RHYAD.

Elle couvre les espaces, équipements et interfaces nécessaires au
contrôle des matières premières, des produits en cours de fabrication et
des produits finis afin de garantir leur conformité avant leur mise à
disposition.

Le présent document décrit exclusivement les besoins fonctionnels du
projet et ne définit ni les méthodes analytiques, ni les procédures
qualité, ni les exigences d'accréditation des laboratoires.

------------------------------------------------------------------------

# 2. Objectifs

-   contrôle qualité des matières premières ;
-   contrôle qualité des produits intermédiaires ;
-   contrôle qualité des produits finis ;
-   gestion des échantillons ;
-   traçabilité des analyses ;
-   qualification et libération des lots ;
-   archivage réglementaire des échantillons et résultats.

------------------------------------------------------------------------

# 3. Périmètre

La fonction couvre notamment :

-   laboratoires de contrôle qualité ;
-   laboratoires microbiologiques ;
-   laboratoires physico-chimiques ;
-   laboratoires de biologie moléculaire si nécessaires ;
-   zones de préparation des échantillons ;
-   locaux de stockage des échantillons ;
-   chambres froides dédiées ;
-   bureaux associés.

Sont exclus :

-   méthodes analytiques ;
-   procédures qualité ;
-   systèmes LIMS ;
-   procédures opératoires.

------------------------------------------------------------------------

# 4. Exigences fonctionnelles

## F08-01 -- Séparation des activités

Les différentes activités analytiques doivent être organisées afin
d'éviter les contaminations croisées.

## F08-02 -- Conditions environnementales

Les laboratoires doivent disposer de conditions adaptées.

Les laboratoires classés doivent garantir : - classe de propreté ; -
cascades de pression ; - température ; - humidité ; - continuité de
fonctionnement.

## F08-03 -- Gestion des échantillons

Les installations doivent permettre : - réception ; - identification ; -
stockage ; - préparation ; - analyse ; - archivage ; - élimination.

## F08-04 -- Traçabilité

Chaque analyse doit être traçable : - échantillon ; - lot ; - opérateur
; - équipement ; - méthode ; - date et heure.

## F08-05 -- Protection des échantillons

Les installations doivent assurer leur conservation.

## F08-06 -- Sécurité

Les laboratoires doivent assurer : - sécurité des opérateurs ; -
protection des échantillons ; - maîtrise des risques chimiques ; -
maîtrise des risques biologiques ; - confinement lorsque requis.

## F08-07 -- Continuité d'activité

Les installations critiques doivent présenter un niveau élevé de
disponibilité.

Sont notamment critiques : - traitement d'air ; - alimentations
électriques sécurisées ; - chambres froides ; - systèmes de supervision.

## F08-08 -- Protection des données

Les résultats analytiques doivent être protégés contre toute perte ou
modification.
