# 1. Objet

Le présent document définit l'organisation documentaire du projet RHYAD.

Il constitue le référentiel de gestion des documents produits pendant la
programmation, la conception, la réalisation et la clôture du projet.

Il garantit :

-   une structure documentaire unique ;
-   une gestion cohérente des versions ;
-   la traçabilité des modifications ;
-   la maîtrise des interfaces documentaires.

------------------------------------------------------------------------

# 2. Domaine d'application

Le présent plan s'applique à l'ensemble des documents produits dans le
cadre du projet RHYAD.

Il couvre :

-   les documents de gouvernance ;
-   les documents fonctionnels ;
-   les données techniques ;
-   les Design Basis ;
-   les réunions ;
-   les registres ;
-   les dossiers d'études.

------------------------------------------------------------------------

# 3. Principes documentaires

La gestion documentaire RHYAD repose sur les principes suivants :

-   une information = une seule source ;
-   un document = une responsabilité identifiée ;
-   une modification = une analyse des impacts documentaires ;
-   une décision = une traçabilité complète ;
-   une version = un historique conservé.

# 5. Convention de nommage

Chaque document suit la convention :

`CEVA-RHYAD-XXX-YYY`

Exemples :

-   CEVA-RHYAD-100-F09
-   CEVA-RHYAD-200-F09-DT01
-   CEVA-RHYAD-300-DB04
-   CEVA-RHYAD-500-REG02

------------------------------------------------------------------------

# 6. Cycle de vie documentaire

1.  Création
2.  Rédaction
3.  Revue
4.  Validation
5.  Publication
6.  Révision
7.  Archivage

Chaque évolution est historisée.

------------------------------------------------------------------------

# 7. Gestion des versions

Chaque document comporte :

-   une référence ;
-   une version ;
-   un statut ;
-   une date ;
-   un historique des révisions.

Les versions obsolètes sont archivées et restent consultables.

------------------------------------------------------------------------

# 8. Gestion des responsabilités

Chaque document identifie :

-   son rédacteur ;
-   son relecteur ;
-   son valideur ;
-   son responsable documentaire.

------------------------------------------------------------------------

# 9. Gestion des interfaces documentaires

Chaque document identifie :

-   ses documents d'entrée ;
-   ses documents de sortie ;
-   les documents liés ;
-   les documents impactés par une modification.

------------------------------------------------------------------------

# 10. Gestion des impacts documentaires

Toute modification d'un document entraîne une analyse des impacts.

Les documents impactés sont :

-   identifiés ;
-   mis à jour ;
-   tracés dans le Registre des Décisions.

------------------------------------------------------------------------

# 11. Source documentaire unique

Les documents sources sont conservés dans le dépôt RHYAD.

Les formats DOCX et PDF sont des livrables générés automatiquement à
partir des fichiers sources.

Les documents générés ne constituent jamais la source de référence.

------------------------------------------------------------------------

# 12. Qualité documentaire

Chaque document doit respecter :

-   cohérence documentaire ;
-   absence de duplication ;
-   traçabilité des décisions ;
-   lisibilité ;
-   homogénéité de présentation ;
-   respect de la méthode RHYAD.

------------------------------------------------------------------------

# 13. Règles de gestion

1.  Une information n'est présente qu'une seule fois dans le
    référentiel.
2.  Toute modification est propagée vers les documents concernés.
3.  Toute décision est enregistrée dans le Registre des Décisions.
4.  Toute évolution documentaire est historisée.
5.  Les documents générés (DOCX, PDF) ne sont jamais modifiés
    directement.
6.  Le dépôt RHYAD constitue la source documentaire officielle du
    projet.
