**Version :** Rev1.0\
**Statut :** Validated\
**Référence :** CEVA-RHYAD-005-REGISTRE DES DECISIONS

------------------------------------------------------------------------

# 1. Objet

Le présent document constitue le registre unique des décisions du projet
RHYAD.

Il assure la traçabilité de l'ensemble des décisions prises pendant la
programmation, la conception, la réalisation et la mise en service du
projet.

Chaque décision est identifiée, justifiée, validée, historisée et reliée
aux documents qu'elle impacte.

------------------------------------------------------------------------

# 2. Domaine d'application

Le registre couvre notamment :

-   les décisions de gouvernance ;
-   les décisions fonctionnelles ;
-   les décisions techniques ;
-   les arbitrages du Maître d'Ouvrage ;
-   les validations des Design Drivers ;
-   les validations des pondérations de la matrice multicritère ;
-   les validations des Design Basis ;
-   les décisions documentaires.

# 4. Principes

Le registre des décisions constitue la référence unique pour toutes les
décisions du projet.

Chaque décision :

-   possède un identifiant unique ;
-   est enregistrée une seule fois ;
-   est datée ;
-   est validée par l'autorité compétente ;
-   référence les documents concernés ;
-   reste consultable même après son application.

# 7. Sources des décisions

Les décisions peuvent provenir :

-   des réunions de projet ;
-   des ateliers fonctionnels ;
-   des ateliers techniques ;
-   des revues APS/APD/PRO ;
-   des analyses de variantes ;
-   des demandes du Maître d'Ouvrage ;
-   des évolutions réglementaires ;
-   des analyses de risques.

------------------------------------------------------------------------

# 8. Cycle de vie d'une décision

1.  Proposition
2.  Analyse
3.  Validation
4.  Mise en œuvre
5.  Vérification des impacts documentaires
6.  Clôture

Une décision clôturée reste présente dans le registre à des fins de
traçabilité.

# 10. Lien avec les Design Drivers

Les décisions relatives aux Design Drivers, aux pondérations de la
matrice multicritère et au choix des variantes doivent être enregistrées
dans le présent registre avec une référence vers le Design Basis
concerné.

------------------------------------------------------------------------

# 11. Lien avec les risques

Toute décision ayant un impact sur un risque doit référencer :

-   le risque concerné ;
-   l'évolution de son niveau de criticité ;
-   les mesures de maîtrise associées.

------------------------------------------------------------------------

# 12. Lien avec les actions

Chaque décision peut générer une ou plusieurs actions.

Les actions sont suivies dans le **CEVA-RHYAD-500-REG01 --- Registre des
Actions**.

------------------------------------------------------------------------

# 13. Règles de gestion

1.  Chaque décision possède un identifiant unique.
2.  Une décision ne peut être enregistrée qu'une seule fois.
3.  Toute décision doit être justifiée.
4.  Toute décision doit identifier ses impacts documentaires.
5.  Toute décision est liée, si nécessaire, aux risques et aux actions
    concernés.
6.  Les décisions sont revues à chaque jalon du projet.

------------------------------------------------------------------------

# 14. Propagation documentaire

Toute décision validée entraîne une analyse des impacts documentaires.

Les documents identifiés sont mis à jour conformément au Plan Directeur
Documentaire.

Cette propagation garantit :

-   la cohérence documentaire ;
-   la traçabilité des évolutions ;
-   l'application du principe « Une information = une seule source ».
