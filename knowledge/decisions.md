# Mémoire des décisions RHYAD

## Références

- Document client : `CEVA-RHYAD-005-REGISTRE DES DECISIONS`.
- Source YAML actuelle : `config/documents/005.yaml`.
- Registre structuré futur : `knowledge/decisions.yaml`.

## Décisions structurantes déjà présentes dans CEVA-RHYAD-005

Le registre des décisions validé pose les règles suivantes :

- le registre des décisions constitue la référence unique pour toutes les décisions du projet ;
- chaque décision possède un identifiant unique ;
- une décision n'est enregistrée qu'une seule fois ;
- toute décision doit être justifiée ;
- toute décision doit identifier ses impacts documentaires ;
- les décisions peuvent provenir des réunions, ateliers, revues, analyses de variantes, demandes du Maître d'Ouvrage, évolutions réglementaires et analyses de risques ;
- une décision validée devient une donnée d'entrée pour les phases suivantes ;
- les décisions relatives aux Design Drivers, aux pondérations et aux variantes doivent être reliées au Design Basis concerné.

| Source officielle | YAML intégré dans le dépôt Git. |
| Livrables | Markdown d'entrée, DOCX et PDF sont des livrables ou artefacts générés. |

## Points de vigilance

La codification DT est harmonisée vers `CEVA-RHYAD-200-Fxx-DT01`. La codification DB coexiste sous plusieurs formes : `DB-001`, `DB01`, `DB001`, `CEVA-RHYAD-300-DB01` et `CEVA-RHYAD-300-DB001`.

Ces écarts doivent être arbitrés dans le registre des décisions avant toute correction documentaire systématique.
