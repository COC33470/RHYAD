# Design Drivers RHYAD

## Définition

Les Design Drivers sont les objectifs qui orientent la conception. Ils sont définis avant toute analyse de variantes et servent de critères de référence pour comparer les solutions techniques.

## Design Drivers identifiés par la méthode

Les critères cités dans `CEVA-RHYAD-000-MTH01` incluent notamment :

- conformité réglementaire ;
- qualité pharmaceutique ;
- sécurité des personnes ;
- sécurité des installations ;
- continuité d'activité ;
- disponibilité des installations ;
- maintenabilité ;
- évolutivité ;
- performance énergétique ;
- CAPEX ;
- OPEX ;
- durabilité ;
- contraintes du contexte local.

## Pondération

Les pondérations sont proposées par l'équipe projet et validées par le Maître d'Ouvrage CEVA. Elles peuvent varier selon le sujet étudié.

## Lien avec les Design Basis

Chaque Design Basis doit définir ses Design Drivers spécifiques. La référence cible reste à harmoniser entre `DB000`, `DB-000`, `DB00` et la série officielle des Design Basis.

## Lien avec la matrice multicritère

Les variantes sont comparées via une matrice multicritère. Les critères proviennent des Design Drivers et les résultats doivent justifier le choix retenu. La décision correspondante est enregistrée dans le registre des décisions.
